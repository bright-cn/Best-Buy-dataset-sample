# Best-Buy 数据集示例

<h2>包含 1001 条 Best Buy 商品的示例数据集</h2>

![Best Buy 商品数据集头图](https://github.com/bright-cn/Best-Buy-dataset-sample/blob/main/Best-Buy-dataset.png)

一个包含 1000 多条记录的 Best Buy 商品数据集示例。该数据集使用 <b>Bright Data API</b> 提取。

<h2>Best Buy 商品数据集中包含的部分数据点：</h2>

* ```url```：商品页面的链接  
* ```product_id```：商品的唯一标识符  
* ```title```：商品标题  
* ```images```：商品图片  
* ```final_price```：折后最终价格  
* ```currency```：定价所用货币  
* ```discount```：折扣百分比或金额  
* ```initial_price```：初始价格  
* ```offer_price```：优惠价/促销价  
* ```root_category```：商品的根类别  
* ```breadcrumbs```：到达该商品的面包屑导航  
* ```release_date```：发布日期  
* ```esrb_rating```：ESRB 评级  
* ```rating```：商品平均评分  
* ```reviews_count```：评论总数  
* ```questions_count```：问答总数  
* ```hot_offer```：热门优惠  
* ```open_box```：开箱品详情  
* ```availability```：可用性详情  
* ```you_might_also_need```：你可能还需要的商品  
* ```variations```：商品变体  
* ```highlights```：商品亮点  
* ```product_description```：商品描述  
* ```features_summary```：功能概要  
* ```features```：商品特性  
* ```whats_included```：包装清单  
* ```q_a```：商品相关的问答  
* ```product_specifications```：产品规格  
* ```amount_of_stars```：星级分布  
* ```customer_images```：用户上传的图片  

还有更多。

这是从 “Best Buy products” 数据集中抽取的样本子集，完整数据集包含超过 <b>26.6K 条记录</b>。

<h2>Best Buy 商品数据集的应用场景有哪些？</h2>

<h3>1. 价格优化</h3>
通过分析并对比 Best Buy 数据集中相似的电子产品与家电类别，以及与竞争对手的差异，制定定价策略并创建动态定价模型。

<h3>2. 产品库存</h3>
借助 Best Buy 数据集识别库存缺口，监控特定电子产品需求的上升趋势，并跟踪流行的消费电子产品。

<h3>3. 市场策略</h3>
利用 Best Buy 数据集开展市场策略分析，识别电子零售领域的主要趋势与消费者偏好。
