# Best Buy 数据集样本

<h2>包含 1001 款 Best Buy 商品的示例数据集</h2>

![Best Buy 商品数据集标题图](https://github.com/bright-cn/Best-Buy-dataset-sample/blob/main/Best-Buy-dataset.png)

包含超过 1000 条记录的 Best Buy 商品数据集示例。该数据集使用 <b>Bright Data API</b> 提取。

<h2>Best Buy 商品数据集包含的部分数据点：</h2>

* ```url```：商品 URL  
* ```product_id```：商品 ID  
* ```title```：商品标题  
* ```images```：商品图片  
* ```final_price```：商品折后最终价格  
* ```currency```：商品价格币种  
* ```discount```：折扣百分比或金额  
* ```initial_price```：商品原价  
* ```offer_price```：商品优惠价  
* ```root_category```：商品根类别  
* ```breadcrumbs```：指向商品的面包屑导航  
* ```release_date```：商品发布日期  
* ```esrb_rating```：商品 ESRB 分级  
* ```rating```：商品平均评分  
* ```reviews_count```：商品评论总数  
* ```questions_count```：商品问题总数  
* ```hot_offer```：商品热门优惠  
* ```open_box```：商品开箱品详情  
* ```availability```：商品库存详情  
* ```you_might_also_need```：你可能还需要的商品  
* ```variations```：商品变体  
* ```highlights```：商品亮点  
* ```product_description```：商品描述  
* ```features_summary```：商品功能摘要  
* ```features```：商品功能  
* ```whats_included```：商品包装清单  
* ```q_a```：商品相关问答  
* ```product_specifications```：商品规格  
* ```amount_of_stars```：星级评分分布  
* ```customer_images```：客户上传的图片  

以及更多内容。

这是“Best Buy 商品”数据集的示例子集，完整数据集包含超过 <b>26.6K 条记录</b>。

可用的数据集文件格式：<b>JSON、NDJSON、JSON Lines、CSV 或 Parquet。还可选择将文件压缩为 .gz</b>。

数据集交付方式选项：<b>电子邮件、API 下载、Webhook、Amazon S3、Google Cloud Storage、Google Cloud PubSub、Microsoft Azure、Snowflake、SFTP</b>。

更新频率：<b>单次、每日、每周、每月、每季度或自定义</b>。

可在已提取的数据点基础上添加数据增强：<b>根据需求提供。</b>

<b>[获取完整的 Best Buy 商品数据集](https://www.bright.cn/products/datasets/best-buy)</b>。

<h2>Best Buy 商品数据集有哪些使用场景？</h2>

<h3>1. 定价优化</h3>
通过分析和比较 Best Buy 数据集及竞争对手中类似的电子产品和家电类别，制定定价策略并创建动态定价模型。

<h3>2. 商品库存</h3>
使用 Best Buy 数据集识别库存缺口、监测特定电子产品不断增长的需求，并追踪热门消费电子产品。

<h3>3. 市场策略</h3>
利用 Best Buy 数据集开展市场策略分析，识别电子产品零售行业的主要趋势和消费者偏好。
